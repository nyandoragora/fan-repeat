# Event モジュール

## 1. 概要
イベント情報を一覧またはカード形式で表示するコンポーネント。  
写真・タイトル・概要などをコンパクトに提示し、ユーザーが「詳細を見る」や「参加」などのアクションをスムーズに行えるようにします。

---

## 2. 責務
- イベント情報のビジュアル表示（写真・タイトル・紹介文）  
- 詳細モーダルの開閉制御  
- 参加ボタン操作（確認モーダルの表示）  
- イベント状態（満席／開催中／終了）の表示切り替え  

---

## 3. 非責務
- イベントデータの取得（EventList側で管理）  
- 参加登録処理・メール送信（バックエンド担当）  
- モーダルコンポーネント自体のデザイン構築（Modal Controllerに依存）  

---

## 4. 依存関係
| 依存モジュール | 目的 |
|----------------|------|
| **Modal Controller モジュール** | 詳細／参加確認モーダルの表示管理 |
| **EventList モジュール** | イベントカードの親リスト |
| **Notification モジュール** | 参加操作後の通知制御 |
| **State Controller** | 参加状態やモーダル開閉状態の共有 |

---

## 5. 開発メモ
- **カード構成**：画像上部＋タイトル・紹介・アクション下部  
- **アクセシビリティ**：画像には代替テキスト必須  
- **ステータス表示**：「開催中」「終了」「満席」など色分け  
- **Bubble実装**：RepeatingGroup内セルでモーダル表示制御  
- **React実装**：`useState`＋`framer-motion`で開閉アニメーション  
- **UX最適化**：モーダルから参加操作→完了→トップへ戻る一連動線をシンプルに保持

# EventFilterモジュール README

## 1. 概要
EventFilterモジュールは、イベント一覧ページにおいてユーザーがイベントを容易に検索・絞り込みできる機能を提供します。  
ソートや検索条件入力により、目的のイベントを迅速に発見できるよう支援します。

## 2. 責務
- 開催中、日付順、人気順のソート切替
- 日付、場所、参加費、主催者、タグによる検索条件入力
- 検索条件のクリア（リセット）
- 入力変更やソート切替を親コンポーネントへ通知（`onFilterChange` コールバック）

## 3. 非責務
- 実際のイベント一覧表示やフィルタリング処理は担当しない
- バックエンドとの通信や検索結果の取得は行わない
- タグの自動補完や履歴管理は本モジュール外で対応

## 4. 依存関係
- 親コンポーネント：`onFilterChange` コールバックを受け取り、検索結果更新
- CSSモジュール：`EventFilter.module.css` でスタイル管理
- 標準のReact Hooks（useState）で状態管理

## 5. 開発メモ
- 各入力ボックスは controlled component として管理
- `sortKey` はボタンの `active` クラスと連動させる
- クリアボタン押下でフィルタ条件を初期化する
- レスポンシブ対応のため、flexbox と wrap を活用
- タグ入力はオプション補完機能を将来的に追加可能

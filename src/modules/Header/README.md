# Header モジュール

## 1. 概要
Header モジュールは、ユーザーがアプリ全体をスムーズに操作できるようにするための **全ページ共通ナビゲーション** を提供します。  
特にスマートフォン利用を想定し、必要な情報・アクション（ログイン、登録、イベント・求人作成依頼など）へ素早くアクセスできる導線を確保します。  
また、アカウント種別（一般／企業／管理者）に応じて表示内容を動的に切り替えることで、ユーザー体験のシンプル化を図ります。

---

## 2. 責務
- アプリ全体で共通するナビゲーションバーの提供  
- ログイン状態／アカウント種別に基づくリンクの出し分け  
- 各ページ・モーダルへのルーティング制御（SPAとしての動的切り替え）  
- 文字サイズ変更機能の提供（高齢者向けアクセシビリティ対応）  
- モーダル開閉のトリガー管理（求人広告作成依頼・イベント作成依頼）  
- ログイン／ログアウトアクションのUI制御  

---

## 3. 非責務
- 各ページ・モーダルの内部ロジック（フォーム送信やAPI通信など）は担わない  
- アカウント認証処理そのもの（JWT管理、セッション制御など）は対象外  
- 通知・メッセージ表示（別モジュールで制御）  
- レイアウト全体のレスポンシブ処理（ベースレイアウト側が管理）  

---

## 4. 依存関係
| 依存モジュール | 目的 |
|----------------|------|
| **Auth モジュール** | ログイン状態の取得・ユーザー種別判定 |
| **Modal Controller モジュール** | 求人／イベント依頼モーダルの開閉制御 |
| **Router モジュール** | ページ遷移（React Router または Bubble 内リンク） |
| **Profile モジュール** | プロフィールリンク・アカウント情報参照 |
| **Typography Controller** | 文字サイズ変更機能との連携 |

---

## 5. 開発メモ
- **アクセシビリティ重視**：タブ移動で主要リンクにアクセス可能にする  
- **レスポンシブ設計**：スマホ表示時はハンバーガーメニュー化を想定  
- **状態管理**：`useContext` または `zustand` などでログイン状態を参照  
- **企業ユーザー限定機能**：求人広告作成依頼リンクの条件分岐に注意  
- **送信後挙動**：モーダル送信完了後、トップページへリダイレクト（状態リセットを含む）  
- **UI統一性**：サイトテーマカラーに合わせたボタン・リンクデザインを統一

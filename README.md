# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) (or [oxc](https://oxc.rs) when used in [rolldown-vite](https://vite.dev/guide/rolldown)) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

## 使用技術・ライブラリ
- **React**: フロントエンド開発のためのJavaScriptライブラリ。
- **Vite**: 高速な開発サーバーとビルドツール。
- **React Router DOM**: シングルページアプリケーションにおけるルーティング機能を提供。
- **Swiper**: タッチスライダー（カルーセル）機能を提供。
- **CSS Modules**: コンポーネントごとのスタイルをカプセル化し、グローバルな名前の衝突を防ぐ。

## セットアップ手順
1.  **リポジトリのクローン**:
    git clone https://github.com/nyandoragora/fan-repeat
    cd fan-repeat

2.  **依存関係のインストール**:
    npm install

3.  **開発サーバーの起動**:
    npm run dev    
    ブラウザで `http://localhost:5173` (または表示されたURL) にアクセスしてください。

## 実装機能
### 1. イベント一覧ページの表示
- ダミーデータを用いてイベントカード形式でイベント一覧を表示します。
- 各イベントカードには、イベント名、日付、場所、簡単な説明、画像が表示されます。
- イベント一覧はSwiperコンポーネントによりスライド形式で閲覧可能です。

### 2. イベントフィルター機能
- 日付、場所、参加費、主催者、タグによるイベントの絞り込みが可能です。
- 「開催中」「日付順」「人気順」の3種類のソート機能を提供します。
- 「開催中」ソートでは、当日開催中のイベントのみが表示されます。
- モバイルサイズでは、フィルタリングボックスはデフォルトで非表示となり、ボタンをタップ・クリックすることで開閉できます。

### 3. イベント詳細モーダル
- イベントカードの詳細ボタンをクリックすると、イベントの詳細情報（開催時間、参加費、主催者、詳細な説明など）がモーダルで表示されます。

### 4. ログイン機能と管理者ダッシュボード
- ヘッダーの「ログイン」リンクから専用のログインページに遷移できます。
- ログインページでは、「管理者」「企業」「一般ユーザー」として仮のログインが可能です。
- ログイン状態は`localStorage`に保存され、ページリロード後も維持されます。
- 管理者としてログインした場合、ヘッダーに「管理者ダッシュボード」リンクが表示されます。
- 管理者ダッシュボードでは、企業ユーザーからのイベント作成依頼一覧を確認し、承認または拒否することができます。
- 企業ユーザーとしてログインした場合、ヘッダーに「イベント作成依頼」ボタンが表示され、モーダルからイベント作成依頼を送信できます。

### 5. 全体的なスタイリングとレスポンシブデザイン
- 自然をイメージしたカラーパレットを`src/App.css`で定義し、アプリケーション全体で統一感のあるデザインを適用しています。
- ヘッダーはモバイルサイズでハンバーガーメニューに切り替わり、ナビゲーション要素がスライドインする形式で表示されます。
- イベントカードはモバイルサイズで画面幅いっぱいに表示され、画像やボタンが適切に配置されます。
- イベントフィルターはモバイルサイズで開閉可能となり、コンテンツがコンパクトに表示されます。

## 動作確認方法
以下の手順で各機能の動作を確認してください。

1.  **イベント一覧の表示確認:**
    - ブラウザでアプリケーションを開き、ダミーデータが正しくイベントカードとして一覧表示されていることを確認してください。
    - 各イベントカードに、イベント名、日付、場所、簡単な説明が表示されていることを確認してください。

2.  **フィルター機能の動作確認:**
    - 日付フィルター、カテゴリフィルター、キーワード検索など、実装したフィルターをそれぞれ操作し、イベント一覧が正しく絞り込まれることを確認してください。
    - フィルターを解除した際に、全てのイベントが再表示されることを確認してください。
    - 「開催中」ソートボタンをクリックし、当日開催中のイベントのみが表示されることを確認してください。該当のイベントがない場合は「該当するイベントが有りません。」という表示になります。
    - モバイルサイズでフィルタ開閉ボタンが表示され、クリックでフィルタリングコンテンツが表示/非表示になることを確認してください。

3.  **イベント詳細モーダルの動作確認:**
    - いずれかのイベントカード内にある詳細ボタンをクリックし、モーダルが正しく表示されることを確認してください。
    - モーダル内に、イベントの詳細情報（開催時間、参加費、主催者、詳細な説明など）が表示されていることを確認してください。
    - モーダルを閉じるボタンや、モーダル外をクリックすることで、モーダルが閉じられることを確認してください。

4.  **ログイン機能の動作確認:**
    - ヘッダーの「ログイン」リンクをクリックし、ログインページに遷移することを確認してください。
    - ログインページで、管理者、企業、一般ユーザーのいずれかを選択してログインできることを確認してください。
    - ログイン後、イベント一覧ページにリダイレクトされることを確認してください。
    - ログイン状態に応じて、ヘッダーの表示（「ログイン」が「ログアウト」に変わるなど）が切り替わることを確認してください。
    - ログアウトボタンをクリックすると、ログアウトされ、ヘッダーの表示が元に戻ることを確認してください。

5.  **管理者ダッシュボード機能の動作確認:**
    - ログインページで「管理者としてログイン」を選択し、管理者としてログインしてください。
    - ヘッダーに「管理者ダッシュボード」リンクが表示されることを確認してください。
    - 「管理者ダッシュボード」リンクをクリックし、ダッシュボードページに遷移することを確認してください。
    - ダッシュボードページに、ダミーのイベント作成依頼が表示されていることを確認してください。
    - 各依頼の詳細情報が正しく表示されていることを確認してください。
    - 「承認」ボタンをクリックすると、依頼のステータスが「approved」に変わり、ダッシュボード上でその変更が反映されることを確認してください。
    - 「拒否」ボタンをクリックすると、依頼のステータスが「rejected」に変わり、ダッシュボード上でその変更が反映されることを確認してください。
    - 一般ユーザーや企業ユーザーでログインした場合、管理者ダッシュボードへのリンクが表示されないこと、およびURLを直接入力してもダッシュボードページにアクセスできないこと（ホームページにリダイレクトされること）を確認してください。

6.  **イベント作成依頼モーダルの動作確認:**
    - ログインページで「企業としてログイン」を選択し、企業ユーザーとしてログインしてください。
    - ヘッダーに「イベント作成依頼」ボタンが表示されることを確認してください。
    - 「イベント作成依頼」ボタンをクリックし、モーダルが表示されることを確認してください。
    - モーダル内の各入力フィールドに情報を入力し、「送信」ボタンをクリックしてください。
    - 「イベント作成依頼を送信しました」というアラートが表示され、モーダルが閉じることを確認してください。

7.  **全体的なスタイリングの確認:**
    - アプリケーション全体で、自然をイメージした新しいカラーパレットが統一的に適用されていることを確認してください。
    - 特に、全体の背景、ヘッダー、フィルターコンポーネントの背景色が意図通りになっているかを確認してください。
    - ログインページのボタンの縁取りが常に表示されていることを確認してください。

8.  **レスポンシブデザインの確認 (最終):**
    - ブラウザのウィンドウサイズを小さくしていき、以下の点を確認してください。
        - **ヘッダー**: ハンバーガーメニューが表示され、クリックでメニューがスライドイン/アウトすることを確認してください。メニュー内の要素（文字サイズコントロール、ナビゲーション、企業向けボタン）が縦並びで適切に表示されていることを確認してください。
        - **イベントカード**: カードが画面幅いっぱいに表示され、画像と情報が縦方向に適切に配置されていることを確認してください。ボタンも縦並びで操作しやすいことを確認してください。
        - **イベントフィルター**: フィルタ開閉ボタンが表示され、クリックでフィルタリングコンテンツが表示/非表示になることを確認してください。フィルタリングコンテンツが表示された際に、各要素が縦並びでコンパクトに表示されていることを確認してください。
        - 全体的に、小さな画面でもレイアウトが崩れず、各要素が操作しやすいことを確認してください。
